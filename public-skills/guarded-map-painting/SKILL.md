name: guarded-map-painting
description: Run layout-preserving map painting with representative spot review, immutable settings, semantic compositing and resumable frame verification.
---

Read the supplied runner before executing it. Check for another active painting process and verify its run identity before starting or resuming. Freeze geometry, camera, terrain, dimensions, overlap, tool settings and source hashes.

Run representative spots before a costly full grid. Show the actual spot image and obtain any user-required appearance approval before proceeding. Describe appearance neutrally through colour, texture, foliage and architectural detail. Do not substitute a model, quality setting or method without authorisation.

Keep image generation separate from geometry and picking IDs. For different architecture and landscape treatments, combine outputs through authoritative semantic masks and restore exact alpha. Inspect current geometry, roads, silhouette, edges and shared context.

Reject weak or ambiguous alignment, warped layout, missing coverage and large context changes. A translation repair must not wrap pixels. Bounded overlap colour correction and feathering can reduce seams but cannot repair geometry. Keep failed attempts distinct from accepted outputs.

Resume only when input and settings hashes match. Skip a frame only if its accepted output hash verifies. On usage limits, record the stop and wait for permitted availability; rerun the same command when allowed. Keep checking through completion when monitoring was requested, and honour a user stop immediately.

Before replacing a tile set, verify the complete mosaic, tile manifest, backup and a settled painted-view screenshot. Report accepted frames, context flags, coverage flags, execution failures, mosaic location and backup/replacement results. Keep real outputs and operational details outside methods-only publication.
