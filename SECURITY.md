# Security and disclosure

This is a reference library, not a hosted service. Only the current default branch is maintained.

For a non-sensitive input-validation or algorithm defect, open a minimal synthetic issue. For suspected credentials, personal information, operational details or restricted data, use [GitHub private vulnerability reporting](https://github.com/felizvida/nichd-map/security/advisories/new) when enabled. Never paste a suspected value into a public issue, commit or screenshot. If private reporting is unavailable, use an existing private contact channel with the repository owner.

Deleting a file from the latest tree does not remove Git history. Stop publication on a boundary failure, preserve evidence privately and inspect reachable history before proceeding.
